# Reference implementation (TMR 2026)

Verbatim copies of `scripts/maestro.py` (v8) and `scripts/vision.py` (v6) as they ran at
the Mexican Robotics Tournament 2026. They are **not used by the robot**. The golden tests
(`tests/test_golden_*.py`) run them side by side with the refactored package and require
identical outputs, so the refactor cannot silently change the robot's behaviour.
